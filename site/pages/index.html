PDFPundit

A forensic PDF repair tool in pure Rust. It rebuilds damaged PDFs from their raw bytes and tells you which parts it recovered and which it had to make up.

Start contributing View on GitHub

Research stage. There is no working tool yet. The work so far is the design and an evidence base for the repair engine.

The roadmap shows what's done and what's next.

What it will do

  1. You give it a damaged PDF.
  2. It carves every object that survives in the file's bytes.
  3. It rebuilds the cross-reference table, trailer, page tree and fonts.
  4. It writes a new file, <name>.repaired.pdf. The original is never changed.
  5. It labels every part of the output with how it was obtained.

Later milestones add PDF to Markdown export and optional OCR. Repaired fonts give correct Unicode, so the export works on files that other tools can't read.

Why it exists

Most PDF readers repair quietly. They guess, and they don't say what they guessed. Different engines even guess differently on the same file, and attackers use those differences.

PDFPundit treats a damaged PDF as evidence. That means it has to report every choice it makes.
