Research guide

The research lives in research/. Every fact the engine design relies on is a record there, and a validator checks the evidence behind it.

Read these first

  1. research/README.md. Status and a map of every file.
  2. research/charter.md. The goal, the definitions and the rules.
  3. research/agents/brief-template.md. The rules for adding records.

Each JSONL file has a generated Markdown view next to it. Don't edit the views, because the next render overwrites them.

What counts as evidence

Only three things count. The validator checks all three.

EvidenceWhat it needs
Verified quoteFound in the cached full text, at least 8 words, on the right page. Every number in your summary must appear in the quote.
Code citationFound in the cited lines of the file, at a pinned commit
ObservationA committed script with pinned inputs

Your own reasoning is a critique. Critiques are recorded but never count as evidence. Anything from memory is a lead to check, not a fact.

Workflow

  1. Get a staging folder. Work in research/staging/<your-name>/. Ask for an ID block, so your IDs don't clash with anyone else's.
  2. Check what's known. Read the gap register and the source index first, so you don't redo work.
  3. Cache the source. Use fetch_fulltext.py for documents or fetch_code.py for code. The validator can't check a quote without the cached text.
  4. Write records. Follow the schemas in research/schemas/.
  5. Validate. The validator must print 0 errors.
  6. Merge. The maintainer merges your folder with merge_staging.py.

Commands

# one-time setup, plus poppler-utils for pdftotext
pip install pypdf pdfminer.six pymupdf rapidfuzz jsonschema

python research/tools/kb_validate.py                  # must print 0 error(s)
python research/tools/kb_validate.py --write --online # recheck quotes and DOIs
python research/tools/render_views.py                 # rebuild the .md views
python research/tools/test_kb.py                      # tests for the validator

python research/tools/fetch_fulltext.py SRC-xxxx <url-or-path>
python research/tools/fetch_code.py SRC-xxxx <git-url> <sha> --license <SPDX>
python research/tools/merge_staging.py research/staging/<name>

The REPDF corpus

REPDF's corpus is 1.6 GB, so it isn't in this repository. Clone it next to your checkout, pinned to commit e547d4d.

GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/dfrc-korea/repdf

Use it for replication and regression only. It's too well known to serve as a held-out test.

Committees

Big decisions go through a review committee. The minutes live in research/committees/.

  • The chair answers every blocking objection with a reason.
  • If the chair rejects a blocking objection, the maintainer decides.
  • One member spot-checks 5 random claims against the raw sources.
