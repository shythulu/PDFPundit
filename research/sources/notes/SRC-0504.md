# SRC-0504 — Poppler recovery behaviour

**Copyleft (GPL).** Our own description of behaviour only. Poppler's test PDFs live in a separate
repository, registered as SRC-0506.

## Recovery techniques (our words)
- **Broken xref (a).** Reconstruction is triggered when the xref cannot be read, when a circular xref
  chain is found, when the trailer has no valid size, or when the catalog cannot be fetched. It scans
  4 KiB buffers for `trailer` and `endstream` **at line starts**, `nnn ggg obj` after whitespace
  (tolerating digits split across lines), and `>> stream` to note stream objects; afterwards it parses
  each stream object and uses XRef streams as trailer candidates and ObjStm headers as compressed
  entries (CLM-0532).
- **Which copy wins (i).** New entry replaces an existing one if the slot is free or the new generation is
  ≥ the old; ObjStm members are registered with their index as "generation", so they tend to replace
  generation-0 uncompressed copies found earlier in the scan (CLM-0533). Trailer: the last candidate
  with `/Root` wins, except in catalog-recovery mode where only the first is kept (CLM-0534; the
  catalog path calls reconstruction with that flag, XRef.cc ~L1290–1302).
- **Stream length (b).** After reconstruction, a stream ends at the next line-start `endstream` recorded
  during the scan, regardless of `/Length`; otherwise `/Length` is tried and, if `endstream` is not there
  and no xref is available, 5k bytes are added as a kludge (CLM-0535).
- **Truncation (d).** Running off the end right after `stream` returns no stream; otherwise data up to EOF
  is used.
- **Flate (g).** Default build uses Poppler's own inflater (zlib is an off-by-default option described
  as "not totally safe"); running out of input ends the stream and keeps the output (CLM-0536).
- **Fonts / ToUnicode (f).** Missing fonts are substituted (base-14 by flags, or system fonts) with a
  logged message (CLM-0537). For 8-bit fonts without ToUnicode, glyph names are parsed with ligature
  splitting and numeric-name heuristics (hex or decimal detected per font) (GfxFont.cc ~L860–945).
- **Encryption (h).** Missing `/ID` → empty ID string (CLM-0538).
- **Page tree (e).** A `/Pages` root that is really a single `/Page` is recovered as a one-page document;
  invalid/implausible `/Count` values are rejected (CLM-0539); loops in the Pages tree are detected.
- **Guards.** ≤4096 XRefStm entries; ObjStm with >1,000,000 objects rejected; parser recursion limits.

## Test corpus
Main repo: none. poppler/test (SRC-0506): 83 PDFs (OBS-0500), mostly feature tests (signatures,
forms, encryption); few damaged.

## Not checked
Qt/GLib bindings; `pdfsig` behaviour on repaired files; JBIG2/JPX error paths; FoFi font parsers.
