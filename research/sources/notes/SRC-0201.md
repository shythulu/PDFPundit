# SRC-0201 — SafeDocs wide-reach corpus (JPL)

- Sources: Common Crawl (2013 onwards, file-type detection on every file, re-pull of truncated PDFs),
  Sparkler focused crawls, and custom API scrapers for issue trackers (Ghostscript Bugzilla, PDFBox and Tika JIRA) (CLM-0271).
- **Truncation prevalence:** Common Crawl truncates at 1 MB, and 22% of PDFs in the December 2019 crawl
  were truncated (CLM-0270). This is independent of, and consistent with, the 2021 counts in SRC-0206.
- Feature extraction on 20,000 GovDocs1 + Common Crawl files with Tika and ClamAV; no parse-error
  statistics reported.
- The issue-tracker harvesting is the origin of the later "Stressful PDF Corpus" (pdfa.org page
  blocked from this container with HTTP 403; lead only).
