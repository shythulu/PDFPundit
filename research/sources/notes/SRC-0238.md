# SRC-0238 — PDF Association corpus index

**Why it matters:** it names a second public source of *real-world malformed* PDFs besides the
Common Crawl truncations: the SafeDocs Issue Tracker ("stressful") corpus. It also names an
adversarial corpus: UNSAFE-DOCS.

- **Issue Tracker corpus:** >32K PDFs (>31 GB) from bug-report attachments of open-source PDF tools
  (CLM-0293), with a higher-than-normal share of malformed files (CLM-0294). Download:
  corpora.tika.apache.org/base/docs/bug_trackers/ (reachability not checked). Files are named by bug
  ID, so each has a linked human description of what broke. That is a weak damage label.
  Caveat: no known originals, so under charter §3(a) these count for robustness only.
- **UNSAFE-DOCS (CC-MAIN-2021-31-UNSAFE):** >5.0M files, JPL-collected or generated by Kudu Dynamics'
  "Voice of the Offense" team (CLM-0296). Contains malformed and malicious files (CLM-0295). Its Common
  Crawl component (>3.9M) *includes truncated PDFs* (CLM-0297). These can be paired with the untruncated
  versions in SRC-0206, giving a second route to natural pairs. Handle as hostile input (sandbox only).
- Also indexed: GovDocs1 (231K PDFs), IUST-PDFCorpus (6,141 files, used for learned fuzzing),
  the Library of Congress .gov 1,000-PDF set, and others. These leads were not screened as separate sources.

**Overlap:** the engine-study agent is characterising engine test corpora (git status shows
`research/experiments/engine_test_corpora.py`). The chair should dedupe corpus records by hand,
because this record has no DOI and its title key will not collide.
