# SRC-0500 — qpdf recovery behaviour

Permissive licence: techniques and short code may be reused with attribution (still: describe
behaviour in specs, don't paste code into PDFPundit).

## Recovery techniques (our words)
- **Broken xref (a).** Header is searched in the first 1024 bytes and its absence is only a warning.
  `startxref` is looked for near EOF; if it (or the table/stream it points at) is unusable, qpdf deletes
  every uncompressed xref entry and rescans the entire file token by token for `N G obj` and `trailer`
  (CLM-0500). Before rebuilding, if no `startxref` was found in the last ~1 KiB but the scan saw one
  after the last object, it first tries the xref that one points to. Object ids larger than file-size/3 are ignored (guard).
- **Duplicates / which copy wins (i).** Scanned headers are inserted in reverse file order into a table
  that keeps the first insertion, so the last copy in the file wins (CLM-0501). The same "first insertion
  wins" rule makes the newest xref section win in normal (incremental) reading.
- **Trailer choice.** Only the last 100 `trailer` candidates are tried, newest first; the first one with
  `/Root` wins. If none, the XRef stream with the largest `/Size` (ties: later offset) is read and used;
  failing that, a `/Catalog` found among loaded objects becomes `/Root` of a synthesized trailer
  (QPDF_objects.cc ~L420–490).
- **Object streams (c).** No carving inside ObjStm during reconstruction (CLM-0502); compressed objects
  survive only through a readable XRef stream. Self-referential or impossibly large ObjStm ids are
  rejected.
- **Stream /Length (b) and truncation (d).** Missing/wrong length → search for `endstream`/`endobj`,
  accepted only if no other known object starts inside the span; otherwise the stream is **empty**
  (CLM-0503). A stream running into a truncated EOF therefore loses its bytes.
- **Flate (g).** Adler-32 mismatch ("incorrect data check") is treated as end of stream (CLM-0505).
  When decoding fails during writing, qpdf re-writes the stream **unfiltered**, i.e. keeps the original
  compressed bytes rather than a decoded prefix (CLM-0504) — the forensically conservative choice.
- **Encryption (h).** Missing/invalid `/ID` → empty string, with a warning (CLM-0506).
- **Page tree (e).** Direct kids made indirect, `/Type /Page` forced, missing `/Resources` replaced by
  an empty dict, missing MediaBox set to US Letter (a content synthesis, grade 6 in our charter terms);
  after reconstruction pages with >2 such errors are dropped; duplicated page objects are copied (normal
  file) or dropped (reconstructed file) (CLM-0507).
- **Fonts (f).** Not applicable: qpdf does not render text.
- **Guards.** Reconstruction aborts after 1000 additional warnings (QPDF_objects.cc ~L318–327); a Flate
  memory limit exists in Pl_Flate ("PL_Flate memory limit exceeded"); token length is capped at 10 bytes
  while scanning.
