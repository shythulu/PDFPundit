# SRC-0202 — Caradoc (LangSec's reference study of PDF structure)

**Why it matters:** the one LangSec paper that combines (a) crafted-file differential tests of
real readers, (b) a strict grammar plus normalizer, and (c) numbers from ~10,000 real web PDFs.
Its normalizer is a CDR-style rewrite, so its design choices are a direct warning for PDFPundit's emitter.

## Method
- **Reader study (§4):** crafted ill-formed/ambiguous files against Adobe Reader, Evince, Foxit,
  SumatraPDF, Chrome and Firefox viewers: outline cycles, duplicate dictionary keys, `#` escapes in names,
  undefined/negative/65535 generation numbers.
- **PDF/Restricted (§5):** a formal grammar for a linear, non-incremental, no-object-stream subset;
  type checker (165 types) and graph checks.
- **Normalization (§6.3):** a relaxed parser follows xref tables, then rewrites the file into the subset.

## Findings (verified quotes)
- Real-world set: 10000 files from search-engine queries (CLM-0200); only 1465 pass the strict parser
  (CLM-0201); most use incremental updates (CLM-0202).
- Normalizer drops every object unreachable from the trailer and renumbers (CLM-0203); rewrote 8993/10000.
- **Real producer bug:** in-use xref entries at offset zero; common enough to need a tolerance flag
  (CLM-0204, CLM-0205). A concrete DMG-011 template with real-world provenance.
- Differentials: `/Foo#7/Bar` tokenized differently (CLM-0208); generation-number fallback (CLM-0209);
  duplicate keys resolved "last wins" by every reader (CLM-0210, a common-mode behaviour).
- Readers silently correct errors (CLM-0211); cycles cause infinite recursion (CLM-0215, CLM-0216);
  incremental updates need not follow their predecessor, so `/Prev` loops are possible (CLM-0217).
- JHOVE's PDF module declared a crashing ill-formed file "well-formed and valid" (CLM-0213).

## Limitations and future work (verified)
- Equivalence of normalized output checked only manually, on a restricted set (CLM-0206).
- Tolerance options cover only common bugs (CLM-0207); most stream filters unchecked (CLM-0212).

## Our reading (not evidence)
- Figure 16/17 (table layout, not quotable) report the share of files by number of incremental
  updates and forbidden structures; worth re-extracting with `pdftotext -layout` if a number is needed.
- The normalizer is exactly the "collapse to one revision" emitter that GAP-016 warns against: it
  deletes unreachable objects (earlier revisions, shadow content) by design (CLM-0291).
- Its tolerance flags are an early, open-source (code public) catalogue of real producer bugs; the
  engine study should diff it against qpdf/MuPDF recovery code.
