# SRC-0506 — Poppler test files

Poppler keeps its test PDFs outside the main repository. 83 PDFs (`unittestcases/`, `tests/`):
feature tests for signatures, forms, optional content, encryption, attachments and fonts. qpdf flags
11 of them (8 for more than linearization hints) and 3 need a password (OBS-0500). Small, and mostly
well-formed: useful as a clean control set for encryption/signature handling, not as a damage source.
Use for analysis only; the per-file licences are not stated, so never redistribute.
