# SRC-0129: NIST IR 8354 (tool testing, error and recovered data)

**Why it matters:** this is the authoritative US statement on how forensic tools are validated,
and it is the evidence base for charter §3(c) and the P6 validation report. It gives us:
- an error taxonomy that maps onto fabrication, omission and source-mixing;
- the precedent for scoring recovered files by data returned, omitted and not-from-original.

## Key content
- **Recovered data is risky.** Deleted or partially overwritten data may not be separable into
  original and overwriting parts (CLM-0119). CFTT tests found carving and deleted-file recovery
  results can miss data or mix sources (CLM-0120).
- **Error taxonomy (sec. 4.10.2):**

  | Error type | Meaning | Maps to |
  |---|---|---|
  | incompleteness | data not acquired or found | omission |
  | inaccuracy: existence | reported data absent from the original (CLM-0121) | fabrication |
  | inaccuracy: alteration | data changed | |
  | inaccuracy: association | information linked to an unrelated item (CLM-0122) | source mixing |
  | inaccuracy: corruption | whether missing or corrupt data is detected and compensated | |
  | misinterpretation | results understood wrongly | |

- **Error rates.** Digital tools fail systematically, not randomly, so error-mitigation analysis
  beats a single error rate (CLM-0126). When rates are given, their context matters.
- **CFTT scoring of carvers (sec. 4.11).** Two measures:
  - a visual check;
  - how much of the original is returned, omitted, and not from the original (CLM-0123).

  A hash-only pass/fail comparison hides near misses (CLM-0127).
- **Scope of CFTT's static data sets:** graphic and video carving, deleted-file recovery and
  string search. No document formats are listed (CLM-0124).
- **No standard to test against.** There are no agreed requirements or formal standards for
  forensic tool testing (CLM-0125).
- **Further research** (ch. 5): shared forensic reference data (CLM-0128), more consistent tool
  testing, and better analysis of misleading conclusions.

## Transfer to PDF repair (our reading)
- CFTT's carving measures are exactly the charter's omission and fabrication rates. The error
  taxonomy supplies test-assertion categories for a PDF-repair spec (GAP-050).
- Association errors are the forensic name for source mixing (GAP-051, DMG-050).
- Systematic error argues for a per-condition catalogue of failures in the P6 validation report,
  not just aggregate rates (GAP-055).
- Referenced but not fetched here: the NIST CFTT *Forensic file carving tool specification v1.0*
  and *test assertions and test plan* (both 2014), plus DHS test reports for PhotoRec and others.
  These are good templates for a PDF-repair test spec.
