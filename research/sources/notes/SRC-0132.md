# SRC-0132: syntactic reassembly of fragmented OOXML

**Why it matters:**
- OOXML is the nearest neighbour to PDF among fragmented-document recovery targets: a container
  with offsets, holding DEFLATE-compressed, structured text.
- The method shows how container offsets, compression continuation and a checksum can order
  shuffled clusters (GAP-054).

## Method
1. **Anchor the known clusters.** Find the clusters holding ZIP central-directory records and
   local headers. Directory offsets give each element's start cluster and the lengths of the
   unfilled gaps.
2. **One missing cluster.** Try each unknown cluster between the known start and end, and accept
   it when the element inflates and its stored CRC-32 of the uncompressed data matches (CLM-0130).
3. **Longer gaps.** Extend one cluster at a time. A candidate must continue the DEFLATE stream
   without error (CLM-0129) and yield a well-formed XML structure. The structural filter is
   needed because continuation alone admits almost any bitstream (CLM-0131). The CRC-32 is
   checked at the end.

## Evaluation
- **Corpora:** DOCX files from Govdocs1 (157 unique) and NapierOne (4,992 unique).
- **Damage:** each file is split into 4096-byte blocks, and the blocks are shuffled.
- **Results:**
  - 82.97% of documents were reconstructed (CLM-0132);
  - 85.76-98.73% of main texts were recovered;
  - document.xml is the weak spot, with about 14% errors.

## Limitations and future work
- It is a simplified setting: the search space is thousands of times smaller than a real disk,
  and all fragments are known to belong to one document (CLM-0133).
- Embedded media and nested OOXML packages aren't handled.
- Gaps of 2-4 contiguous unknown clusters aren't searched exhaustively.
- The authors ask for better XML verification (CLM-0135).
- Mid-stream DEFLATE damage of up to 4096 bytes already prevents accurate reconstruction
  (CLM-0136, citing Brown 2013).

## Real-world damage evidence
- Citing van der Meer et al. 2021 (SRC-0137): about 51% of DOCX files were in three or more
  fragments, and 72% of those were out of order (CLM-0134). This is a named real-world damage
  source for DMG-006 (charter §3(a)).
- Govdocs1 and NapierOne are public real-world originals (that NapierOne includes PDFs is from
  memory and unverified). They are
  candidates for held-out originals that are disjoint from SRC-0002 and cover more producers
  (GAP-002).

## Transfer to PDF (our reading)
PDF's analogues of the OOXML signals:

| OOXML signal | PDF analogue |
|---|---|
| central-directory offsets | xref table or stream offsets (when they survive) |
| element sizes | `/Length` |
| CRC-32 of the uncompressed element | zlib Adler-32 (weaker; see GAP-052) |
| XML well-formedness | content-stream operator grammar and object syntax |

No PDF method using these signals was found.
